Cuál me descargo

Windows

El .exe es el instalador. Al abrirlo puede que Windows avise de que viene de un editor desconocido. Eso ocurre porque el instalador no lleva un certificado de firma de pago. Pulsa en Más información y después en Ejecutar de todas formas.

Ya instalada, la aplicación se actualiza sola cuando sale una versión nueva. Si prefieres que no lo haga, se apaga en Ajustes.

Android

Descarga el .apk y ábrelo. Como no viene de Google Play, Android te pedirá permiso para instalar aplicaciones de esta procedencia. Se concede una vez y ya no vuelve a preguntar.

El APK universal vale para cualquier móvil o televisor, y es el que querrás salvo que te importe el tamaño. Si te importa, el de arm64 sirve para casi todo lo fabricado en la última década; el de armv7, solo para dispositivos antiguos de 32 bits.

Linux

FicheroParaCómo se instala
.deb Debian, Ubuntu, Mint sudo apt install ./LinceBlob_*.deb
.rpm Fedora, openSUSE sudo dnf install ./LinceBlob-*.rpm
.AppImage Cualquier distribución Dale permiso de ejecución y ábrelo, sin instalar nada

Comprueba lo que descargas. Cada release incluye los resúmenes SHA-256 de los ficheros. En Windows, certutil -hashfile fichero SHA256; en Linux y macOS, sha256sum fichero. Si el resultado no coincide con el publicado, no lo instales.

{% comment %} El `?v=` cambia con cada publicación, para que el navegador no siga usando una copia guardada del script cuando cambia cómo se agrupan las descargas. {% endcomment %}
