Cuál me descargo

Windows

El fichero .exe es el instalador. Al abrirlo, Windows puede avisar de que es de un editor desconocido: es porque el instalador no está firmado con un certificado de pago. Pulsa en Más información y luego en Ejecutar de todas formas.

Una vez instalado, la aplicación se actualiza sola cuando hay versión nueva; puedes desactivarlo en Ajustes.

Android

Descarga el .apk y ábrelo. Como no viene de Google Play, Android pedirá permiso para instalar aplicaciones de esta procedencia; hay que concederlo una vez.

El APK universal vale para cualquier móvil o televisor. Si prefieres uno más pequeño, los que llevan arm64 en el nombre sirven para prácticamente todo lo fabricado en la última década, y los armv7 solo para aparatos antiguos de 32 bits.

Linux

FicheroParaCómo se instala
.deb Debian, Ubuntu, Mint sudo apt install ./LinceBlob_*.deb
.rpm Fedora, openSUSE sudo dnf install ./LinceBlob-*.rpm
.AppImage Cualquier distribución Dale permiso de ejecución y ábrelo, sin instalar nada

Comprueba lo que descargas. Cada release incluye los resúmenes SHA-256 de los ficheros. En Windows, certutil -hashfile fichero SHA256; en Linux y macOS, sha256sum fichero. Si el resultado no coincide con el publicado, no lo instales.
